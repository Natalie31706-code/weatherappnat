# Natalie's Weather App

### Project Overview
A responsive weather application built with React that uses the WeatherAPI to display real-time weather information for different locations. Users can search for a city and view its current weather conditions through a simple and user-friendly interface.


### Live Demo
[View the Website](https://weatherappnat.vercel.app/)
### Video Preview
[Watch the Website Demo](https://youtu.be/s7V2IXWP1Vw)


## Key Features

- City Weather Search
- Real-Time Weather Data
- Temperature & Weather Conditions
- Wind Speed & Direction
- Humidity & Precipitation
- Visibility Information
- Location Details
- Local Time & Last Updated Time
- Responsive Design
- Interactive UI
- Keyboard Search
  

## Technologies Used
`React.js` `Vite` `JavaScript` `Axios` `Bootstrap` `React Bootstrap` `React Router` `WeatherAPI` `ESLint` `npm` `Git & GitHub` `Vercel`
#### API
Product data is fetched dynamically from both the [Current Weather API](https://api.weatherapi.com/v1/current.json)

## Installation
1. Clone the repository
```bash
git clone https://github.com/Natalie31706-code/weatherappnat.git
```

2. Navigate to the project folder
```bash
cd weatherappnat
```

3. Install dependencies
```bash
npm install
```

4. Run the development server
```bash
npm run dev
```
The project will be available at the local development URL provided by Vite.

## Project Purpose
The purpose of this project is to provide users with a simple and interactive way to search for cities and access real-time weather information through the WeatherAPI.
